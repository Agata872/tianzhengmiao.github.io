Efficient Fronthaul Compression in Distributed Wireless Network Architectures

Reducing the radio data exchanged between access points and processing units while preserving the information a distributed network needs.

Background

Distributed wireless systems connect many access points and processing units. Moving radio information between them puts communication capacity and computation in the same design picture.

This research area explores efficient fronthaul compression for distributed wireless network architectures. It complements my work on cell-free networking and physical-layer signal processing, where coordination and computational cost both matter.

Questions I Am Exploring

  1. How can fronthaul communication overhead be reduced while retaining useful information for downstream processing?
  2. How should processing and cooperation be shared across access points, distributed units, and the central processor?
  3. How can communication efficiency be considered alongside interference and practical computational complexity?
